## 📖 Descripción del Proyecto

El proyecto **Página Web Nuevo Horizonte** busca digitalizar y modernizar la presencia institucional del colegio. Proporciona una interfaz intuitiva donde se destacan:

- Noticias y eventos recientes de la institución.
- Información sobre actividades deportivas y recreativas.
- Módulos informativos sobre cronogramas y horarios académicos.
- Ubicación de sedes e instalaciones (mapas interactivos y galerías).
- Estructura HTML Semántica y validada de acuerdo con las especificaciones del W3C.

---

## ✨ Características Principales

- **Diseño Responsive:** Adaptado a dispositivos móviles, tablets y pantallas de escritorio.
- **Sección de Noticias y Actividades:** Tarjetas dinámicas e imágenes representativas de eventos deportivos y comunitarios.
- **Navegación Intuitiva:** Menú estructurado que facilita el acceso rápido a la información académica.
- **Validación Estricta de Código:** Implementación semántica probada con captura y documentación de validación de etiquetas HTML (`href`, `table`, `section`).

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica del contenido (`<header>`, `<nav>`, `<section>`, `<table>`, `<footer>`).
- **CSS3:** Maquetación moderna, hojas de estilo personalizadas (`estilos_index.css`) y diseño adaptable.
- **JavaScript (JS):** Lógica del lado del cliente e interactividad del portal.
- **W3C Standards:** Prácticas de validación HTML/CSS.

## 📋 Documentación y Validación de Estándares

Como parte del desarrollo técnico y la garantía de calidad web, se realizaron pruebas de validación de etiquetas para asegurar el cumplimiento de las normas del W3C. Puedes consultar los soportes en la carpeta `Documentacion/validacion de etiquetas/`:

- **Atributos y Enlaces (`href.png`):** Verificación de rutas relativas y absolutas correctas.
- **Secciones Semánticas (`section.png`):** Uso apropiado de etiquetas semánticas para estructura de contenido.
- **Estructura de Datos (`table.png`):** Uso correcto de tablas para visualización de horarios e información académica.

## 🚀 Instalación y Uso Local

Para ejecutar el proyecto localmente en tu navegador:

1. **Clonar o descargar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/Pagina_Web_Nuevo_horizonte.git
   ```

2. **Acceder a la carpeta del proyecto:**
   ```bash
   cd Pagina_Web_Nuevo_horizonte
   ```

3. **Abrir el sitio web:**
   Abre el archivo `index.html` directamente en tu navegador preferido (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) o utiliza la extensión **Live Server** en Visual Studio Code.
